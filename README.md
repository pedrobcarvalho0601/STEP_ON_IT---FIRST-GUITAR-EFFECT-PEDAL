# STEP_ON_IT — FIRST GUITAR EFFECT PEDAL

My hobby is playing guitar; I’ve been playing for several years, and I’m currently studying Electrical and Computer Engineering.
Normally, I have access to guitar effects through an amplifier, but since I’m studying away from home, I’m using an amp without those effects. One day I thought: what if I built a pedal myself?
I had already built a simple amplifier with two transistors for a college project, so I did have some prior experience. That’s when I decided to dive into the world of pedal building.
I started studying and fell in love with the hobby. Since then, I’ve been creating various circuits — distortion effects, fuzz, gain, and more.
However, I had never completed a full pedal, and that is now my mission. I will be posting my entire process here.

STEP ON IT will be my “brand”, and the first pedal I’ll build will be a dual-effect pedal: a combination of fuzz and overdrive.

The fuzz will be inspired by the famous Fuzz Face. I’ll use two stages with PNP transistors and shape the tone using a few filters.
The overdrive will be a simple two-stage transistor circuit. The first stage will provide gain, and then the sound will be distorted by three diodes using an asymmetric clipping configuration.
Both circuits will be connected with an SPDT switch, allowing the user to choose which effect they want.

To make the process more challenging, improve the experience, and aim for a more elegant design, I will build the entire circuit without using a PCB — soldering point-to-point directly onto the components.
